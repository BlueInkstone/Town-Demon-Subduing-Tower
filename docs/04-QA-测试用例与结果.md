## 3. 用例明细（34 项）

### 3.1 风险分级（RiskGate，FR-3/FR-4/FR-6）
- R0 readLog / R1 restartService / R2 deployService / R3 deleteData 分级正确
- 复合命令 `rm -rf / ; echo hi` 取最高 → R3
- 未知 risk("ZZ") 与空 risk → 默认 R2
- 只读命令带 `> ` 重定向 → 升级 R1（不按只读放行）
- AST 解析失败（引号不配对）→ R2，且 `astFallbackCount>=1`

### 3.2 意图与置信度（FR-1/FR-2）
- 置信度 <0.5 → `NEED_MORE_INFO`（非拒绝）
- 建议文本「建议你执行 X」→ `INTENT_FORMAT_INVALID`

### 3.3 模式白名单与模式状态机（FR-6/FR-7）
- PLANNING 调 writeFile → `MODE_TOOL_NOT_ALLOWED`；PLANNING 调 splitTask 放行
- DEV 调 splitTask（重规划）→ `MODE_TOOL_NOT_ALLOWED`；DEV 调 writeFile 放行
- 非法转换 AUDIT_REVIEWING --PLAN_APPROVED（跳过 REPLAN）→ `MODE_TRANSITION_INVALID`
- 合法 PLANNING --PLAN_APPROVED → DEV_EXECUTION

### 3.4 闸门与审批（FR-3/FR-5）
- R3 即使高置信/含 `--force` → `R3_DENIED`
- R2 部署 → `PENDING_APPROVAL`（挂人工，返回 ticketId）
- 权限不足 → `PERMISSION_DENIED`，**且审计记录数≥1、哈希链仍完整**（FR-12）

### 3.5 状态落盘（FR-13）
- PipelineState save/load 后 mode、subTasks、gate 一致

### 3.6 门禁脚本（FR-10）
- 签名被篡改 → 拒绝（`SIGNATURE_MISMATCH`）
- 执行器恒失败、重试耗尽（maxRetry=2 → 3 次）→ 失败
- 执行器恒成功 → passed（1 次）

### 3.7 审批策略与 Guardian（FR-11）
- R3 → `REFER_MANUAL_TERMINAL`（永不 APPROVE）
- R2 → `ESCALATE_TO_HUMAN`（置信度 100% 也不自动放行）
- Guardian 对 R2 标记 risky，**仅预审不代批**

- **功能正确性**：最小链路「意图校验→模式白名单→RiskGate→拒绝/放行」全部分支行为符合 README v1.3 基线（R0 放行 / R1 轻确认 / R2 人工 / R3 拒绝）。

- **可审计性**：任何拒绝/异常均追加写哈希链审计，验证链完整。
