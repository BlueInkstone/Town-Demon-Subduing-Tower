## 4. 执行报告结论（原 docs/28）

- 对照测试清单逐项实测，全仓全过且连跑两遍幂等；首轮唯一失败为 Docker 镜像拉取环境问题，非实现缺陷。
- 清单标注缺口经代码级核查全部属实，部分描述失准已修正。
- 新增发现：多实例锚点少计、已执行未留证、缺回归用例、租户隔离实为空转等，均如实记录。
- 产物一致性：已装 starter jar 曾丢失 `-parameters` 属性，已用编译产物重装保证下游与自测同一字节码。

## 6. 运行方式

编译/运行按各模块自带 main 运行器（零 surefire 依赖）；core 的编译必须显式 `--release 8`，否则产物在 JRE 8 上 `UnsupportedClassVersionError`。`out/` 是本地编译输出，不提交、不拷进分发包；对外发布一律 `mvn clean package`（`clean` 不能省）。
