# 产品定位与工程思想

> 合并自原 `docs/16`（定位）、`docs/17`（强制力边界）、`docs/15`（可编排设计）。本文是定位与边界的**唯一权威出处**，别处只引用。

## 1. 一句话定位

**给 Agent 装「刹车和行车记录仪」的治理层**：用一条顺序写死的检查链裁决「这次工具调用能不能执行」，并把所有结果（含拒绝与异常）写进只追加的哈希链供事后追溯。

两种接入形态：

- **嵌入式（默认）**：starter 嵌进宿主 Spring Boot 应用，加依赖 + 注解，运行时进程内拦截。
- **网关（v2.0）**：独立 Web 服务暴露 `POST /api/evaluate`；客户端只发一个 `IntentObject` JSON，任意语言接入。**网关只裁决、不执行**，接入见 `docs/网关接入指南.md`。

## 2. 它是什么、不是什么

| | |
|---|---|
| **是** | 固定 10 环节检查链；不可篡改的审计追溯；构建期防绕过扫描；既可作为嵌入式库，也可作为独立裁决网关 |
| **不是** | 开发时/CI 工具（扫描只是补漏）；服务器/主机/内核层安全（不碰 seccomp、LSM、网络层）；跨信任域防恶意机制；SaaS / 可视化编排平台；服务端执行工具 |

## 3. 强制力边界（原 docs/17）

- 治理是**框架层强制**，嵌入式边界 = JVM 进程边界；网关边界 = 「调用方是否先调 `/api/evaluate`」。
- 挡得住「用错」，挡不住「想绕」：自调用、`private/final/static`、直调下层 Service、方法体内自己做 IO、换恒真策略 Bean、工具方法体内开子进程、重算哈希链、未认证 HTTP 调用者，都不在保护范围。
- 治理对象是「这一次调用」，不是它产生的效果；OS 层隔离交给接入方。
- 审计哈希链保证「断链可见」；外锚 + 副本提升证据强度，但挡不住副本收集端本身被删。
- 网关形态从设计上就**不试图阻止「不调网关就执行」**——这一点如实写明。

## 4. 可编排设计（原 docs/15，尚未实现）

- 「可编排」= 把流程写成文本，与业务代码同编辑器、同 commit、可 diff、可 review、可 CI 校验，而非 GUI 表单。
- `agentflow` / `agenthub` / `agenthub.yml` 是同一 IR 的三种声明面，共享 `FlowRunner` 运行时。
- 铁律：**编排层可变、治理层固定**——固定 10 环节顺序不可拖拽，否则 Audit 被拖走审计链当场失效。
- 状态：设计稿，**尚未实现**，不进验收基线。

## 5. 工程思想（本项目想传播的部分）

1. **模型只提议，闸门硬裁决**。提示词是建议，闸门是机制。
2. **机制写死，策略可配**。链顺序与层数固定，配置不能改拓扑；策略对象可替换但须与契约测试对齐。
3. **三层 AND**：业务态允许（状态机）+ 动作允许（风险闸门 R0-R3）+ 工具允许（模式白名单）。
4. **默认配置即安全**。不配置也不降低安全性；放松须显式写出，被自检记录、被审计留痕。
5. **审计是证据，不是控制输入**。日志重放/注入会把证据当控制输入反而制造拒绝服务——这是「降权建议单要人批准、后台自动收紧明确否决」的根因。
6. **承认边界，而不是把边界藏起来**。管不到的地方明确交给接入方，不假装覆盖了。
7. **文档不撒谎**。设计稿标「尚未实现」、基线标「未整轮重跑」、形态未落地不写「任意语言可接入」。
8. **可追溯、可快照、可回滚、可急停**。被拒绝的调用同样进审计——没有「失败就不记录」的死角。

## 6. 目标用户

个人开发者与 1~3 人小队；正把 Agent 从「聊天」接到「动真格」（写文件/跑命令/部署）；认同「治理应当是固定管线，而不是可拖拽的图形」。网关形态下不限语言——任何能发 HTTP 的运行时都能接。

**不适合**：需要可视化流程设计器、多 Agent 协作派发、多人审批团队协作、需要「服务端替你执行工具」的场景。

## 7. 主要能力

- **治理链**：10 环节固定顺序（审计 → 模式白名单 → 意图格式 → Schema → 能力 → RBAC → 风险闸门 → 污点 → 快照 → 沙箱）。
- **Agent 注册表**：档案「应然权限」与 RBAC「实然权限」逐项对账，停用/注销立即整员回收。
- **可追溯**：SHA-256/HMAC 追加写审计链，任何分支都留痕，链可校验，另有外锚与副本。
- **可回滚**：写前快照；网关只留证、不回滚。
- **跨语言**：一份权威 JSON 协议（`contract/`）+ 网关 HTTP 裁决，不为任何语言维护 SDK。
