3. 裁决结果

还没发过请求。选一个预设，点「发送裁决」。

原始响应

—

裁决码怎么读

OK
放行。网关认为可以执行——但它自己不会执行。
R3_DENIED
默认拒绝，不可逆高危动作，带 force 也不放行。
PENDING_APPROVAL
挂人工审批，响应里带 approvalTicketId。
MODE_TOOL_NOT_ALLOWED
当前模式下这个工具根本不在白名单里。
INTENT_FORMAT_INVALID
意图本身不合法（缺 tool / confidence 非数字 / mode 非法）。
UNAUTHORIZED
缺令牌或令牌错（HTTP 401）。
GATEWAY_API_DISABLED
服务端没配 INKARMOR_API_TOKEN，全拒（HTTP 403）。
每次裁决都会写一条审计（服务端文件，默认 ./data/audit/gateway.log）；探活不写审计。 响应里不含审计序号——审计是落盘证据，不是接口返回值。
